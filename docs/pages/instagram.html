Instagram [sw-instagram]

Galeria de posts do Instagram. Três modos: feed via proxy próprio (sw-instagram-user), embed oficial por URL, ou JSON estático.

1. Modo Feed (requer um proxy no seu backend)

O proxy deve devolver JSON no formato { user, avatar, followers, posts: [{ url, image, caption, likes, comments }] }. Sem token de API — o Instagram não oferece feed público direto por CORS.

2. Modo Embed (posts públicos por URL, sem proxy)
