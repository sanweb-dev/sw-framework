Quick Reference — Controller

Método Descrição
$this->view($view, $dados) Renderiza view PHP
$this->json($dados, $status) Resposta JSON (exit)
$this->redirect($url, $status) HTTP redirect (exit)
$this->back() Redireciona para HTTP_REFERER (exit)
$this->semConteudo() HTTP 204 No Content (exit)
$this->validar($regras) Valida request — aborta/redireciona se inválido
$this->abortar($status, $msg) HTTP error (exit)
$this->autenticar() Exige login ou aborta
$this->pode($perm) Verifica permissão RBAC (bool)
$this->requerPermissao($perm) Exige permissão RBAC ou aborta 403
