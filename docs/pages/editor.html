Editor de Texto SWEditor

Editor de texto rico (contentEditable) leve, nativo e responsivo. Suporta modo completo (com cores, alinhamento, código HTML e tela cheia) e modo simples (apenas B, I, U, S).

1. Modo Simples (B, I, U, S)

Adicione o atributo sw-editor-simple no <textarea> para exibir uma toolbar minimalista apenas com Negrito (B), Itálico (I), Sublinhado (U) e Tachado (S).

2. Modo Completo

Com o atributo sw-editor padrão, ativa a toolbar completa com formatação de bloco (H1–H6), cores de texto/fundo, alinhamentos, listas, links, imagens, modo código HTML e tela cheia.

3. Uso em Formulário Real

O editor gera automaticamente um campo <textarea class="sw-editor-hidden"> mantendo o valor HTML sincronizado e pronto para submeter via POST ou FormData.

Salvo! Confira o console (F12).
