Quick Reference

Atributo/Classe Tipo Descrição
[y2bread] Base Container principal da trilha de navegação.
y2bread-it Item Atributo de cada item da trilha - use em <a> ou <span>.
.y2bread-it-cur Estado Classe no item atual - desativa hover e aplica bold.
.y2bread-chv Separador Separador chevron (>).
.y2bread-dot Separador Separador ponto (.).
.y2bread-dsh Separador Separador traço (-).
--brc-sep CSS Var Caractere separador personalizado (padrão: "/").
.y2bread-bg Estilo Fundo suave com borda e padding.
.y2bread-pil Estilo Variante pill - idêntica ao bg com border-radius total.
.y2bread-sm / .y2bread-lg Tamanho Tamanhos menor e maior que o padrão.
