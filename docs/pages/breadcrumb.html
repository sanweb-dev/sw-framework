ClasseTipoDescrição
.brcBase<nav> container da trilha, separador "/" automático via CSS.
.brc-itItemCada nível — <a> se navegável, <span> se não.
.is-curEstadoMarca o item atual — use com aria-current="page".
.is-arrowSeparadorTroca o "/" por "›".
.is-dotSeparadorTroca o "/" por "•".
.is-pillEstiloCada item vira uma cápsula com fundo; item atual ganha fundo colorido.
.is-barEstiloTrilha inteira dentro de uma barra com borda, como um card raso.
.is-sm / .is-lgTamanhoReduz/aumenta a fonte da trilha inteira.
