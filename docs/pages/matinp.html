Material Input [sw-matinp]

Input com label flutuante estilo Material Design, com validação e máscara embutidas — um pacote fechado, sem precisar combinar sw-valid + sw-mask manualmente.

1. Variantes de estilo

Aplique a classe no .fld-mat (wrapper).

2. Com ícone .fld-mat-ico

3. Validação com sw-matinp

Adicione sw-matinp no input e use os atributos de validação. O módulo JS cria a label (se não existir), hint e mensagem de erro automaticamente.

4. Máscaras automáticas

Use sw-matinp-mask pra formatação automática enquanto digita.

5. Estados visuais

Normal

Válido .is-ok

Erro .is-err

E-mail inválido.

Com hint

Letras e números, sem espaços.

Desabilitado

Textarea
