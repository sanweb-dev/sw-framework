JS Module

Content [sw-content]

Busca um endpoint JSON e renderiza cada item interpolando {{campo}} dentro de um <template>. Diferente do SWAjax (que injeta fragmentos HTML prontos), aqui o servidor devolve dados puros e o template define a apresentação.

Uso

O endpoint pode devolver um array simples, ou { dados: [...], pagina, paginas } quando sw-content-paginate estiver ativo.
