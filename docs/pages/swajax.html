SW MÓDULOS / SW-AJAX

Módulo SW-AJAX

Carrega fragmentos HTML da mesma origem (ou de um elemento interno da própria página) e injeta no destino — modal, painel ou qualquer elemento. Restrito por padrão à mesma origem, com timeout, validação de tipo de conteúdo e reinicialização automática dos módulos SW no HTML injetado.

Como funciona

Qualquer elemento com sw-ajax (URL) ou sw-ajax-src (seletor de um elemento já presente na página) dispara a busca ao ser clicado. O conteúdo é injetado no destino resolvido, os módulos SW no novo conteúdo são reinicializados, e uma transição (SW.Trans.run()) roda por padrão.

<!-- Busca em URL da mesma origem, injeta num elemento -->
<button sw-ajax="/parcial.html" sw-target="#resultado">Carregar</button>
<div id="resultado"></div>

<!-- Copia conteúdo de um elemento já na página, sem requisição HTTP -->
<button sw-ajax-src="#fonte-interna" sw-target="#resultado">Copiar</button>
<template id="fonte-interna"><p>Conteúdo local</p></template>

Injetar em painel ou modal

Use sw-ajax-target="panel" ou sw-ajax-target="modal" para abrir o resultado direto num painel (drawer) ou modal, em vez de um elemento fixo. Combine com sw-panel/sw-modal para escolher o seletor do overlay (opcional — um padrão é criado automaticamente se omitido).

<button sw-ajax="/detalhes.html" sw-ajax-target="modal">Ver detalhes</button>
<button sw-ajax="/menu.html" sw-ajax-target="panel">Abrir menu</button>

Restrições de segurança

  • Só busca URLs da mesma origem por padrão — outra origem exige sw-ajax-crossorigin explícito no elemento.
  • Timeout fixo de 15 segundos por requisição (via AbortController).
  • Resposta precisa ter Content-Type text/html ou text/plain — qualquer outro tipo é rejeitado.
  • Conteúdo injetado passa por SW.html.set(); use sw-ajax-trusted apenas quando a fonte for realmente confiável.

Eventos

Disparados no próprio elemento gatilho:

trigger.addEventListener('sw:ajax:start', ({ detail }) => {
  console.log('Buscando:', detail.url);
});

trigger.addEventListener('sw:ajax:done', ({ detail }) => {
  console.log('Concluído.');
});

trigger.addEventListener('sw:ajax:error', ({ detail }) => {
  console.error('Falha:', detail.error);
});

Referência de atributos

AtributoDescrição
sw-ajaxURL a buscar (GET, mesma origem por padrão)
sw-ajax-srcSeletor de um elemento/template já presente na página — sem requisição HTTP
sw-targetSeletor CSS do elemento de destino (quando não é painel/modal)
sw-ajax-targetpanel ou modal — injeta no overlay correspondente
sw-panel / sw-modalSeletor do painel/modal a usar (opcional, um padrão é criado se ausente)
sw-ajax-trustedPula a sanitização — usar só com fonte confiável
sw-ajax-crossoriginAutoriza buscar URL de outra origem (bloqueado por padrão)
