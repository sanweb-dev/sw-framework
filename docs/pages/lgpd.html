SWLgpd Cookie Consent (4 Modelos)

Banner de consentimento de cookies em conformidade com a LGPD/GDPR. Possui 4 modelos visuais, suporte a inicialização via HTML ou JavaScript, persistência em localStorage e callbacks de aceite/rejeição.

1. Demo ao Vivo (Testar os 4 Modelos)

Clique em qualquer um dos 4 modelos abaixo para ver o banner em ação na parte inferior da página.

2. Os 4 Modelos Visuais

Defina o modelo visual via sw-lgpd-modelo="1" no HTML ou modelo: 1 via JavaScript.

Barra fixa na parte inferior ocupando toda a largura da tela.

1 Barra inferior Padrão

Máxima visibilidade e clareza para o usuário.

Card no canto inferior esquerdo, flutuante e menos intrusivo.

2 Card flutuante

Excelente para sites com layouts densos.

Barra inferior centralizada e compacta com CTAs diretos.

3 Compacto centralizado

Layout limpo e minimalista.

Fundo escuro fixo com alto contraste independente do tema da página.

4 Dark / High-Contrast

Garante elegância e leitura em qualquer tema.

3. Uso via Atributo HTML

Adicione sw-lgpd em qualquer elemento HTML. O banner é carregado e o elemento âncora é removido do DOM.

4. Uso via JavaScript (SWLgpd.init)

Inicialize via JS com callbacks e controle de expiração.

SWLgpd.init({
    msg: 'Usamos cookies para melhorar sua experiência.',
    accept: 'Aceitar todos',
    reject: 'Recusar',
    link: '/privacidade',
    linkTxt: 'Política de privacidade',
    modelo: 2,          // 1 | 2 | 3 | 4
    days: 365,          // dias até o consentimento expirar
    key: 'meu_lgpd',    // chave no localStorage

    onAccept() {
        console.log('Consentimento aceito!');
        carregarGoogleAnalytics();
    },

    onReject() {
        console.log('Consentimento recusado.');
    }
});

// Limpar consentimento para forçar reexibição do banner
SWLgpd.clear('meu_lgpd');
