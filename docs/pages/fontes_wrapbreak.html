Wrap & Break

Controle avançado sobre quebras de texto e balanceamento visual para layouts responsivos impecáveis.

Balanceamento Moderno (.twr-*)

Utiliza algoritmos do navegador para distribuir o texto de forma harmoniosa entre as linhas.

.twr-b

Text Wrap Balance

Título do SW Fica Perfeitamente Balanceado
.twr-p

Text Wrap Pretty

O algoritmo 'pretty' analisa as quebras para evitar que a última linha fique muito curta ou com hifens isolados.

Truncagem e Clamp

Utilize reticências automáticas para textos que não podem ocupar muito espaço.

.truncate

Truncate (1 Linha)

Este texto é cortado com reticências logo no final da primeira linha disponível.
.clamp-1 / .clamp-2 / .clamp-3 / .clamp-4

Line Clamp (N Linhas)

O Line Clamp permite limitar o texto a um número específico de linhas antes de aplicar as reticências, ideal para resumos de cards.
