JS Module

SWCotacao

Cotações de câmbio em tempo real via AwesomeAPI (awesomeapi.com.br) — API pública brasileira, sem token, sem configuração. Suporta moedas tradicionais, criptomoedas e atualização automática.

1. Demo — Tabela Completa

Modo sw-cotacao-mode="table" — exibe preço de compra (bid), venda (ask), variação, máxima e mínima do dia. Atualiza a cada 60s.

2. Demo — Cards

Modo padrão cards — compacto, ideal para widgets e barras de cotação. Atualiza a cada 30s.

3. Compra — Venda

Use sw-cotacao-tipo para escolher entre preço de compra (c - bid) ou venda (v - ask). O modo tabela sempre exibe os dois.

Venda (ask)

4. Auto Refresh

Use sw-cotacao-auto com o intervalo em milissegundos. Omita ou use 0 para desativar.

5. Pares Suportados

Todos os pares disponíveis via AwesomeAPI. Use o código no atributo sw-cotacao-pares, separados por vírgula.
