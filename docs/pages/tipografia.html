Escala de Tamanhos

Escala PP→XXG (1rem = 10px), degrau real — cada tamanho é maior que o anterior. É tamanho puro: combine com .f-lt/.f-bd/.f-bk pra escolher o peso. Use .t-{tamanho}.

.t-pp 1.2rem = 12px Extra Pequeno Extra Pequeno (negrito)
.t-p 1.4rem = 14px Pequeno Pequeno (negrito)
.t-m 1.6rem = 16px Base Base (negrito)
.t-g 1.8rem = 18px Grande Grande (negrito)
.t-gg 3.2rem = 32px Muito Grande Negrito
.t-xg 4.8rem = 48px Extra Negrito
.t-xxg clamp(5–6.4rem) Display Negrito

Headings H1-H6

Todos os headings são fluidos com calc(rem + vw). Use .t-h{n} para aplicar o tamanho em qualquer elemento.
