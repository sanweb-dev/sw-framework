Back-End PHP

SWMVC Framework

O motor back-end oficial em PHP 8.3 + MySQL 8.0 do ecossistema SW. Starter Kit / Boilerplate ultrarrápido, seguro (protegido contra SQL Injection, XSS, CSRF) e equipado com matriz dinâmica de permissões (RBAC).

1. Instalação Automatizada em 1 Comando

Para iniciar um novo projeto utilizando o SWMVC como Starter Kit / Boilerplate completo.

Passo a passo CLI

# 1. Configure as credenciais do MySQL no arquivo .env
DB_HOST=127.0.0.1
DB_NAME=meu_novo_projeto
DB_USER=root
DB_PASS=minha_senha

# 2. Execute o instalador CLI automatizado
php install.php
O script install.php executa automaticamente:
  • Criação do Banco de Dados MySQL (caso não exista)
  • Importação do schema_completo.sql (Usuários, RBAC, Mídias, Blog, E-Commerce, Logs e Configurações)
  • Criação da conta Administrador padrão (admin@admin.com / Admin2026!)
  • Estruturação das pastas de upload em public/storage/uploads/ e permissões de log

2. Recursos Nativos da Arquitetura

Módulos nativos encapsulados e integrados por padrão no SWMVC.

Matriz Dinâmica RBAC

Controle total por papel (Admin, Gerente, Editor, Usuário) editável pelo painel /admin/permissoes e verificado via RBAC::pode('modulo.acao').

QueryBuilder Fluente

Interface fluente contra SQL Injection (QB::tabela('users')->buscar()), paginação automática e suporte nativo a Soft-Deletes.

Galeria de Mídias WebP

Upload centralizado com pipeline de thumbnails, otimização automatizada WebP e organização relacional polimórfica.

Logger & Observabilidade

Registro de auditoria e erros em tabela logs com contexto JSON e visualização gráfica no admin.

3. Como Criar Novas Áreas (Admin & Site Público)

Instruções exatas para Humanos e Inteligências Artificiais criarem novos módulos no SWMVC.

1. Adicionando um Novo Módulo no ADMIN (Exemplo: Banners)

// Step 1: Adicionar Tabela no Banco (app/Database/schema_completo.sql)
CREATE TABLE IF NOT EXISTS banners (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    titulo VARCHAR(150) NOT NULL,
    img VARCHAR(255) NOT NULL,
    status CHAR(1) DEFAULT 'A',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

// Step 2: Criar o Model (app/Models/Banner.php)
namespace App\Models;
use SW\Core\QueryBuilder as QB;
class Banner {
    public static function todos() {
        return QB::tabela('banners')->where('status', 'A')->buscar();
    }
}

// Step 3: Criar Controller (app/Controllers/Admin/BannerController.php)
namespace App\Controllers\Admin;
use SW\Core\Controller;
use SW\Auth\RBAC;
use SW\Core\View;

class BannerController extends Controller {
    public function index() {
        RBAC::requerPermissao('banners.ver');
        View::renderizar('admin/banners/index');
    }
}

// Step 4: Registrar Rota (app/Routes/admin.php)
Router::get('/banners', 'Admin\BannerController@index', ['auth']);

// Step 5: Criar View Admin (app/Views/admin/banners/index.php)
<?php use SW\Core\View; View::layout('admin/layouts/app', ['titulo' => 'Banners']); ?>
<div class="flx alc j-sb mb-m page-header-admin">
    <div>
        <h1 class="page-title">Banners</h1>
        <p class="page-subtitle">Gerencie os destaques visuais do site</p>
    </div>
</div>

2. Adicionando uma Nova Página no SITE PÚBLICO (Exemplo: /sobre)

// Step 1: Controller (app/Controllers/Site/SobreController.php)
namespace App\Controllers\Site;
use SW\Core\Controller;
use SW\Core\View;

class SobreController extends Controller {
    public function index() {
        View::renderizar('site/sobre/index', ['titulo' => 'Sobre Nós']);
    }
}

// Step 2: Rota Pública (app/Routes/web.php)
Router::get('/sobre', 'Site\SobreController@index');

// Step 3: View Pública (app/Views/site/sobre/index.php)
<?php use SW\Core\View; View::layout('site/layouts/app', ['titulo' => $titulo]); ?>
<section class="container py-g">
    <h1>Sobre a Empresa</h1>
</section>
