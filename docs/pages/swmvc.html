⚡ Instalação Automatizada em 1 Comando

Para iniciar um novo projeto utilizando o SWMVC como Starter Kit: 

# 1. Configurar credenciais do banco no arquivo .env
DB_HOST=127.0.0.1
DB_NAME=meu_novo_projeto
DB_USER=root
DB_PASS=minha_senha

# 2. Executar o instalador CLI automatizado
php install.php
O script install.php realiza automaticamente:
  • Criação do Banco de Dados MySQL (se não existir)
  • Importação do schema_completo.sql (Usuários, RBAC, Mídias, Blog, E-Commerce, Logs e Configurações)
  • Criação da conta Administrador padrão (admin@admin.com / Admin2026!)
  • Estruturação das pastas de upload em public/storage/uploads/ e permissões de log

🏛️ Recursos Nativos da Arquitetura

Matriz Dinâmica RBAC

Controle total por papel (Admin, Gerente, Editor, Usuário) editável pelo painel /admin/permissoes e verificado via RBAC::pode('modulo.acao').

QueryBuilder Fluente

Interface fluente contra SQL Injection (QB::tabela('users')->buscar()), paginação automática e suporte nativo a Soft-Deletes (lixeira).

Galeria de Mídias WebP

Upload centralizado com pipeline obrigatório de thumbnails, otimização automática WebP e organização relacional polimórfica.

🧩 Como Criar Novas Áreas (Admin & Site Público)

1. Adicionando um Novo Módulo no ADMIN

  1. Tabela SQL: Adicione a tabela no app/Database/schema_completo.sql.
  2. Model: Crie a classe em app/Models/NovoModulo.php utilizando QB::tabela(...).
  3. Controller: Crie app/Controllers/Admin/NovoModuloController.php e chame RBAC::requerPermissao('modulo.acao').
  4. Rotas: Registre o grupo em app/Routes/admin.php sob o grupo ['auth'].
  5. View Admin: Crie a view em app/Views/admin/novo_modulo/index.php usando View::layout('admin/layouts/app') e a classe .page-header-admin.
  6. Sidebar: Proteja o link na barra lateral sidebar.php com <?php if (RBAC::pode('modulo.ver')): ?>.

2. Adicionando uma Nova Página no SITE PÚBLICO

  1. Controller Publico: Crie app/Controllers/Site/PaginaController.php.
  2. Rota Pública: Registre em app/Routes/web.php (ex: Router::get('/pagina', 'Site\PaginaController@index')).
  3. View Pública: Crie app/Views/site/pagina/index.php herdando View::layout('site/layouts/app').
