ANIMAÇÕES & SW-FX / 03

Módulo SW-FX (Interações Avançadas)

Efeitos visuais nativos, leves, sem GSAP, com suporte a prefers-reduced-motion e zero dependências externas.

Typewriter Nativo

Efeito de digitação com cursor piscante e velocidade configurável em data-sw-speed.

<button sw-typewriter data-sw-speed="40">TEXTO TYPEWRITER</button>

SplitText Acessível

Divisão em palavras (words) e/ou caracteres (chars) com aria-label seguro.

SW-FX SPLIT TEXT

<h4 sw-split="words,chars">SW-FX SPLIT TEXT</h4>

Scroll Scrub Nativo

Transição guiada pelo scroll via IntersectionObserver e variável --sw-scrub-progress.

ELEMENTO COM SCROLL SCRUB 
<div sw-scrub>Scrub Progressivo</div>

Marquee Contínuo

Scroll contínuo com pausa automática ao passar o mouse ou focar por teclado.

★ SW-FX MARQUEE CONTINUO ★ 
<div sw-marquee>
  <span>CONTEÚDO MARQUEE</span>
</div>

Tilt 3D Sutil

Inclinação 3D limitada a 6° para mouse e ponteiro fino.

Passe o ponteiro aqui (sw-tilt)

<div sw-tilt>Card com Tilt</div>

Magnetismo Contido

Atração magnética limitada a 8 px em torno do elemento.

<button class="sw-btn" sw-magnetic>Botão Magnético</button>

API JavaScript do SW-FX

Dispare ou resete os efeitos programaticamente:

// Dispara o efeito typewriter num elemento específico
SW.Fx.typewriter(element);

// Dispara o efeito scramble num elemento específico
SW.Fx.scramble(element);

// Reseta todos os efeitos ativos
SW.Fx.reset(document);
