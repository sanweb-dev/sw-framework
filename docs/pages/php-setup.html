Framework PHP nativo — PSR-4, sem Composer, sem dependências externas. DB, Router, Auth, RBAC, Validator, Upload, Cache, Logger e View em um único módulo.

2. Instalação (sem Composer)

Copie a pasta src/php/ para o seu projeto e registre o autoload manual.

3. Opções de App::iniciar()

Chave Tipo Descrição
db array Conexão MySQL: host, banco, user, pass, charset (utf8mb4)
views string Caminho absoluto para a pasta de views
timezone string Fuso horário (padrão: America/Sao_Paulo)
debug bool Exibe erros e stack trace (padrão: false)
sessao bool Inicia sessão automaticamente (padrão: true)
cors array Configura CORS: ['origens' => 'https://meusite.com']

4. .htaccess (Apache)

Para Nginx, redirecione todas as rotas para index.php com try_files $uri $uri/ /index.php?$query_string;.
