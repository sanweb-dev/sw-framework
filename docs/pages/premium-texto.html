Premium — Texto

Split por chars/words/lines, scramble aleatório e efeito typewriter — 3 sistemas declarativos via atributos sw-premium-*. Equivalente ao Lab 05 (demo-text.html) do Smooll original.

Parâmetros disponíveis

Atributo Tipo Descrição
sw-premium-split chars/words/lines Divide o texto e anima cada unidade
sw-premium-split-stagger número (s) Delay entre unidades (sobrescreve o default)
sw-premium-scramble presença Ativa o embaralhamento de caracteres
sw-premium-scramble-chars / -scramble-speed string / número Pool de caracteres e iterações por caractere revelado
sw-premium-typewriter presença Ativa o efeito máquina de escrever
sw-premium-typewriter-speed / -cursor / -repeat / -pause número / string / presença / número Velocidade, símbolo do cursor, loop infinito e pausa antes de apagar

sw-premium-split="lines" é auto-suficiente — o motor injeta overflow:hidden em cada linha. Dois casos exigem CSS da página: (1) split="chars"/"words" com efeitos que saem da caixa (fade-up etc.) — o pai precisa de overflow:hidden, senão os caracteres aparecem abaixo do texto antes de animar; (2) sw-premium-typewriter — o elemento precisa de min-height, senão o layout ao redor pula enquanto digita.
