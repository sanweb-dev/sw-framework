Atributo/Classe Tipo Descrição
[y2div] Base Divisor horizontal base. Conteúdo interno é centralizado automaticamente.
.y2div-ver Direção Divisor vertical - use dentro de flex container com align-items: stretch.
.y2div-dsh Estilo Linha tracejada (dashed).
.y2div-dot Estilo Linha pontilhada (dotted).
.y2div-pri, .y2div-suc, .y2div-ale, .y2div-err Cor Variantes de cor para linha e texto.
.y2div-md Espessura Linha média (2px).
.y2div-th Espessura Linha grossa (3px).
