Text Carousel [sw-carousel]

Troca de textos/depoimentos com 9 efeitos de transição (slide × 4 direções, zoom × 2, bounce, flip, fade), swipe e autoplay.

1. Depoimentos

Container com .sw-carousel-trk (os itens) e, opcionalmente, .sw-carousel-dts (pontinhos, preenchidos sozinhos pelo JS) e .sw-carousel-prv/.sw-carousel-nxt (setas). O conteúdo de cada item é livre — aqui um cartão com avatar, nome e cargo. Autoplay de 4s, arraste/swipe sempre ativo.

3. Variantes mínimas

Quase tudo é opcional. Controles não são obrigatórios — sem eles, ainda dá pra navegar via swipe/arraste ou API. Só .sw-carousel-trk é indispensável.

4. API JavaScript

Controle programático via SW.Carousel, além do evento sw:carousel:change.

5. Sem loop sw-carousel-loop="false"

Trava no primeiro e no último item — clicar em "próximo" no último não volta pro início.

1 de 3 — início.
2 de 3 — meio.
3 de 3 — fim, não volta ao clicar em "›" de novo.
