Via CDN (recomendado)

Cole no <head> do seu HTML. Sem instalação, sem npm, sem build.

Apenas Core — uso geral:

Core + Compl — com módulos avançados (Table AJAX, Editor, Instagram…):

O Compl detecta o Core automaticamente e registra os módulos via SW.use(). Carregue sempre o Core primeiro.

Via Download (self-hosted)

Baixe os arquivos, coloque a pasta fonts/ no mesmo nível do CSS e hospede no seu servidor.

meu-projeto/ ├── y2.min.css ├── y2.min.js ├── sw-compl.min.css ← opcional ├── sw-compl.min.js ← opcional ├── fonts/ ← obrigatório para os ícones │ ├── wficons.woff2 │ ├── wficons.woff │ └── wficons.ttf └── index.html

A pasta fonts/ deve estar no mesmo diretório que o y2.min.css?v=32. Os ícones não carregam sem ela.

No HTML, a ordem importa:

O y2.config.css deve ser carregado depois de todos os bundles SW para que a cascata funcione corretamente — Core, Compl e só então Config.

Cores — Personalização Total

O SW oferece três caminhos para mudar sua identidade visual.

A. Sobrescrita Direta (HEX / RGB)

Se você já tem uma cor exata em HEX ou RGB, pode forçá-la diretamente. Útil para marcas com manuais de identidade rigorosos.

B. Sistema Inteligente (Hues)

Recomendado. Altera apenas o ângulo da matiz (Hue) e o framework gera automaticamente 7 tons harmoniosos, além de estados de hover e focus.

Arraste o slider para ver a cascata em tempo real:

210°
275°

Shades derivados automaticamente:

Badge

Código gerado no seu y2.config.css:

:root { --sw-h-pri: 210; /* azul */ --sw-h-sec: 275; /* roxo */ }

Referência de ângulos de matiz

C. Cores do Navbar Premium

O componente .y2nav-prm possui tokens próprios para controle fino do Glassmorphism e do estado sólido ao scrollar.

Referência de Tokens

Todos os tokens que podem ser sobrescritos no config.

Token Padrão Descrição Afeta
CORES
--sw-h-pri 210 Matiz da cor primária (0–360) Botões, links, acentos, sombras
--sw-h-sec 275 Matiz da cor secundária Badges, variantes secundárias
--sw-h-suc 140 Matiz da cor de sucesso Alertas ok, validação positiva
--sw-h-per 0 Matiz de perigo / erro Alertas err, validação negativa
--sw-h-ale 45 Matiz de alerta Alertas ale, warnings
--sw-pri hsl(210, 100%, 40%) Cor primária direta (override total) Tudo que usa var(--sw-pri)
TIPOGRAFIA
--sw-f-san 'Outfit', 'Poppins', … Fonte principal sans-serif Todo o texto do framework
--sw-f-mon 'JetBrains Mono' Fonte monospace Código, SWCode, tokens
--sw-f-base 1.6rem (16px) Tamanho base do texto Parágrafos, body
ARREDONDAMENTO
--sw-r-m 0.8rem Radius médio — botões, inputs Componentes interativos
--sw-r-g 1.2rem Radius grande — cards Cards, dropdowns, painéis
--sw-r-gg 1.6rem Radius extra — modais Modais, overlays
TEMA (YDDAY)
--sw-bg-bas dark/light automático Fundo da página Background do body
--sw-bg-sur dark/light automático Superfícies (cards, sidebar) Cards, modais, sidebar
--sw-txt-bas dark/light automático Cor principal do texto Headings, parágrafos
--sw-bor dark/light automático Cor das bordas Cards, inputs, dividers
