Sidebar SWSidebar

Painel lateral com 4 modos de comportamento: fixo, toggle por boto externo, colapso interno (cones/texto) e hover.

Modo 1 - Fixed mode="fixed"

Sidebar sempre visível. Sem botão de fechar. Ideal para painéis admin onde o menu é permanente.

Submenu sw-sidebar-sub

Item pai que ao clicar expande/colapsa subitens. Funciona em qualquer modo. Quando a sidebar está colapsada (só ícones), o submenu fica oculto automaticamente.

API JavaScript

// Abrir sidebar (remove [hid]) - modo toggle
SWSidebar.open('#meu-menu');
SWSidebar.open(document.querySelector('[sw-sidebar]'));

// Fechar sidebar (adiciona [hid]) - modo toggle
SWSidebar.close('#meu-menu');

// Eventos disparados automaticamente
sdb.addEventListener('yd:sidebar:open',    () => {});
sdb.addEventListener('yd:sidebar:close',   () => {});
sdb.addEventListener('yd:sidebar:toggle',  () => {}); // collapse: expandiu/colapsou
sdb.addEventListener('yd:sidebar:submenu', e => {
    console.log(e.detail.open);   // true = abriu, false = fechou
    console.log(e.detail.trigger); // o item pai clicado
    console.log(e.detail.items);   // o container de subitens
});

Quick Reference

Atributo Elemento Descrição
[sw-sidebar] aside / div Container principal da sidebar
sw-sidebar-mode="fixed" aside Sempre visível, sem JS - sidebar fixa
sw-sidebar-mode="toggle" aside Oculta por padrão, abre/fecha por botão externo
sw-sidebar-mode="collapse" aside Seta interna alterna expandida / só ícones
sw-sidebar-mode="hover" aside Só ícones; expande ao passar o mouse, fecha ao tirar
sw-sidebar-start="open" aside Modo collapse: inicia expandida (padrão)
sw-sidebar-start="icons" aside Modo collapse: inicia colapsada (só ícones)
[hid] aside Estado: sidebar oculta (translateX) - modo toggle
[col] aside Estado: sidebar colapsada (só ícones) - gerenciado pelo JS
[sw-sidebar-open="#id"] button Botão externo que abre/fecha pelo ID da sidebar
[sw-sidebar-ovl] div Overlay escuro - fecha a sidebar ao clicar (modo toggle)
[sw-sidebar-hdr] div Cabeçalho da sidebar
[sw-sidebar-hdr-ttl] span Título no cabeçalho (oculto quando colapsada)
[sw-sidebar-tgl] button Seta/botão interno - alterna [col] (modo collapse)
[sw-sidebar-mn] nav Container do menu / navegação
[sw-sidebar-it] a / div Item de menu individual
[act] a Item ativo / selecionado
[sw-sidebar-lbl] span Texto do item (oculto quando colapsada)
[sw-sidebar-ttl] p Título de grupo/seção (oculto quando colapsada)
[sw-sidebar-sep] hr Separador horizontal
[sw-sidebar-bdg] span Badge/contador numérico no item
[sw-sidebar-ftr] div Rodapé da sidebar
[sw-sidebar-push] main Elemento que recebe margin-left quando a sidebar abre
[sw-sidebar-sub] a Item pai com submenu - clique expande/colapsa subitens
[sw-sidebar-arrow] i Seta indicadora dentro do item pai (rotaciona quando aberto)
[sw-sidebar-sub-items] div Container dos subitens - deve ser irmão imediato do item pai
