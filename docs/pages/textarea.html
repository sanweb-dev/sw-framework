Auto Textarea [sw-textarea]

Redimensionamento vertical automático para textareas — o campo expande para baixo suavemente conforme você digita novas linhas, com limites de altura mínima e máxima configuráveis.

1. Demo — Crescimento Vertical Automático

Adicione o atributo sw-textarea em qualquer <textarea>. Digite várias linhas ou aperte Enter para ver a altura ajustar automaticamente.

2. Combo: Auto-Resize + Contador de Caracteres

Você pode combinar sw-textarea (redimensionamento vertical) com sw-textlimit (limite de caracteres) no mesmo campo!

Referência de Atributos

Atributo Padrão Descrição
sw-textarea — Ativa o redimensionamento vertical automático ao digitar.
sw-textarea-min 60 Altura mínima inicial em pixels (ou via min-height CSS).
sw-textarea-max 0 (sem limite) Altura máxima em pixels. Ao atingir este limite, a barra de rolagem vertical é exibida.
SW.Textarea.initAll() — Método JS para reinicializar novos textareas dinâmicos na página.
