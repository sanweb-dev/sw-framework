Ícones SVG (IconPark)

O catálogo grande — 2658 ícones em 39 categorias, cada um já é um arquivo .svg real dentro de dist/icons/. Três jeitos de usar: <img> (sem JS, cacheável pelo navegador, funciona em e-mail/PDF), sw-icon (injeta o SVG no DOM via SW.Icon, herda currentColor) ou SVG inline (cole o markup direto, controle total via CSS/JS). Clique num ícone pra escolher o formato e copiar.
