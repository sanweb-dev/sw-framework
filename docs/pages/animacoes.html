Animações Framework

4 camadas: Reveal (scroll trigger) - Timed (one-shot) - Loop (infinito) - Micro (hover). Clique nos demos para repetir.

Elementos entram na tela ao serem detectados pelo scroll via IntersectionObserver. Adicione class="reveal-*" - o SW observa automaticamente.
