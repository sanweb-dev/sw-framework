Quick Reference

Método Descrição
Router::get($uri, $handler, $mw) Rota GET
Router::post($uri, $handler, $mw) Rota POST
Router::put($uri, $handler, $mw) Rota PUT
Router::delete($uri, $handler, $mw) Rota DELETE
Router::any($uri, $handler, $mw) Todos os métodos
Router::grupo($prefixo, fn, $mw) Grupo com prefixo e middlewares
Router::middleware($nome, fn) Define um middleware nomeado
Router::setNamespace($ns) Altera namespace padrão de controllers
Router::despachar() Executa o roteamento — chamar ao final
