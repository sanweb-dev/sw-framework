Quick Reference

Método Retorno Descrição
Auth::configurar($cfg) void Define modelo, campos e rota de login
Auth::login($login, $senha) bool Autentica e cria sessão
Auth::logout() void Destrói sessão e regenera ID
Auth::check() bool Verifica se há sessão ativa
Auth::user() array|null Dados do usuário logado (sem senha)
Auth::id() int|null ID do usuário logado
Auth::nivel() string Nível/role do usuário
Auth::middleware() void Aborta 401/redireciona se não autenticado
Auth::gerarToken($userId, $dias) string Cookie "lembrar-me" persistente
Auth::verificarToken() bool Renova sessão a partir do cookie
