PHP Core

Framework PHP moderno, leve e modular — portado do Y2 PHP. PSR-4 nativo, Router fluido, ORM simplificado e utilitários essenciais. Zero dependências externas (sem Composer).

Portado, testado ao vivo (Router, Validator, RBAC, Model/QueryBuilder contra um banco real) — mas ainda não homologado em produção. Fica em src/php/, não faz parte do build.js/bundles de frontend.

1. Setup Inicial

Coloque os arquivos em src/php/ e inicialize a aplicação no seu index.php.

2. Router

Gerenciamento de rotas com suporte a middlewares, grupos e parâmetros dinâmicos. Ver página completa →

3. Controller

Base para a lógica de negócio, com métodos auxiliares para views e JSON. Ver página completa →

4. Model (ORM)

Abstração simples para manipulação de tabelas do banco de dados.

5. Query Builder

Construção de queries SQL de forma programática e segura.

6. Auth & Sessão

Gerenciamento de autenticação, permissões (RBAC) e persistência de dados em sessão. Ver Auth → · Ver RBAC →

7. Validação

Motor de validação robusto com suporte a múltiplas regras.

Principais regras
