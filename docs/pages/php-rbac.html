Quick Reference

Método Retorno Descrição
RBAC::definir($mapa) void Define todos os papéis e permissões
RBAC::adicionarNivel($nivel, $perms) void Adiciona permissões a papel existente
RBAC::pode($perm, $nivel?) bool Verifica permissão (suporta wildcard *)
RBAC::ehNivel($nivel) bool Verifica nível exato do usuário logado
RBAC::ehAlgum($niveis) bool Verifica se está em um dos níveis
RBAC::requer($nivel) void Exige nível exato — aborta 403
RBAC::requerAlgum($niveis) void Exige um dos níveis — aborta 403
RBAC::requerPermissao($perm) void Exige permissão — aborta 403

Wildcards suportados: '*' (tudo) e 'modulo.*' (todas as permissões do módulo).
