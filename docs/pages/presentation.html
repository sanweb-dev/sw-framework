O que é o SW Framework?
Um ecossistema CSS + JS nativo, zero dependências, com mais de 80 componentes e módulos prontos.

Não. Copie os arquivos de dist/ e comece — sem npm, sem bundler.
Funciona com PHP, React, Laravel?
Sim — é HTML/CSS/JS puro, compatível com qualquer stack de backend ou frontend.
